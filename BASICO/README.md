# Nivel 2: básico

Objetivo: resumir datos y combinar varias tablas.

| # | Lección | Estado |
|---|---|---|
| 07 | Agregaciones: `COUNT`, `SUM`, `AVG`, `MIN`, `MAX` | pendiente |
| 08 | `GROUP BY` y `HAVING` | pendiente |
| 09 | `INNER JOIN` | pendiente |
| 10 | `LEFT`, `RIGHT` y `FULL JOIN` | pendiente |
| 11 | Funciones de texto y fechas (`YEAR`, `DATEPART`, `DATEDIFF`) | pendiente |
| 12 | `CASE WHEN` y manejo de nulos (`ISNULL`, `COALESCE`) | pendiente |
| 13 | `UNION` y `UNION ALL` | pendiente |

**Reto del nivel:** un reporte que cruce varias tablas, por ejemplo ventas por región o nómina por área.
